Student Registration Form

A creative and responsive Student Registration Form developed using HTML, CSS, and JavaScript.

 Project Overview

This project is designed to provide a simple and user-friendly interface for collecting student registration details. The form maintains a clean academic layout with a modern and creative visual design.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
 ✨ Features

- Student Roll Number
- Student Name
- Father's Name
- Date of Birth
- Mobile Number
- Email ID
- Password with Show/Hide option
- Gender Selection
- Department Selection
- Course Selection
- Student Photo Upload
- City
- Address
- Registration Button
- Responsive Design
- Form Validation
 🎨 Design

The project uses a modern academic-themed interface with:

- Gradient background
- Clean registration form layout
- Responsive design
- Styled input fields
- Interactive buttons
- Decorative academic elements
